# ¿Dónde pongo mis ahorros? Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publicar en GitHub Pages una página estática, para celular, que recomiende ETFs para tres tipos de ahorro y
explique rendimiento contra inflación y volatilidad según el plazo. Los datos reales se actualizan solos cada mes.

**Architecture:** Un paquete de Python (`ahorro/`) baja las series (Yahoo, Eurostat, FRED, BCE), las guarda como CSV en
`data/raw/`, las valida, arma la serie de cada instrumento (dato real más proxy, en la moneda de cada vista) y escribe un
JSON por vista en `site/data/`. `site/` es HTML, CSS y JS sin build step, y solo lee esos JSON. Una GitHub Action mensual
corre el pipeline y los tests, comitea los datos y publica `site/` en Pages.

**Tech Stack:** Python 3.12 con `uv`, pandas, yfinance, requests, PyYAML y pytest. JS vanilla con SVG a mano. GitHub
Actions con `actions/deploy-pages`.

**Spec:** `docs/superpowers/specs/2026-10-19-ahorro-design.md`. El mockup de referencia (números inventados) está en
`docs/mockup/index.html`.

## Global Constraints

- Usar `python`, nunca `python3`. Las dependencias se manejan con `uv` (`uv run ...`).
- Período común para todos los instrumentos y vistas: desde **2010-01** hasta el último mes disponible.
- Vistas: `es` (EUR, HICP de España), `ea` (EUR, HICP de la zona euro, `geo=EA`) y `us` (USD, `CPIAUCSL`). La vista
  por defecto es `es`, y se puede preseleccionar con `?pais=es|ea|us`.
- Inflación de Eurostat: `prc_hicp_minr`, `coicop18=TOTAL`, `unit=I15`. Nunca usar `prc_hicp_midx`.
- Yahoo con `auto_adjust=True`, precio mensual de cierre de fin de mes.
- Cuenta remunerada: tasa de referencia menos 0,5 puntos, con piso de 0% (€STR, y EONIA antes de 2019-10; en la vista
  `us`, `TB3MS`).
- Plazos: 1, 3, 5 y 10 años. Escenario sobre 10.000 en moneda de hoy: Peor = mínimo, Típico = mediana, Mejor = máximo.
- "Rendimiento por año sobre la inflación" = anualizado real de los últimos 120 meses.
- Textos en castellano llano, sin jerga (nada de Sharpe, desvío ni drawdown). Etiqueta del destacado: "el que yo usaría".
- Pie: fecha de datos, "se actualiza cada mes", "rendimientos ya descontadas las comisiones", "datos desde 2010", "antes de
  que existiera cada ETF se usa el índice que replica", la nota fiscal de España y "no es asesoramiento financiero: es lo
  que yo usaría en tu lugar".
- Colores de grupo: liquidez `#1baf7a`, mediano `#2a78d6`, jubilación `#eb6834`. Inflación en gris `#8a8983`, punteada.
- Commits sin trailer `Co-Authored-By`. Test rojo = no hay push: `uv run pytest > /tmp/ahorro-test.log; rc=$?; [ $rc -eq 0 ] && git push`.

## Review Focus

1. **Un mes sin dato en una fuente** (Yahoo no tiene el último mes de un ticker, o Eurostat publica más tarde que
   Yahoo). El pipeline tiene que recortar todas las series al último mes común, no dejar un `NaN` que se propague a la
   página. Se prueba en Task 4 (`test_build_recorta_al_ultimo_mes_comun`).
2. **Una fuente falla en la corrida mensual** (timeout, 429 de Yahoo). Hay que usar el CSV cacheado, avisar en el log y
   publicar igual con la fecha correcta. Se prueba en Task 3 (`test_actualizar_usa_cache_si_falla`).
3. **Salto absurdo en una serie** (split sin ajustar, como el −96% de SPYI.DE). La validación tiene que frenar la
   escritura del JSON y el build tiene que salir con código distinto de 0. Se prueba en Task 2 (`test_validar_detecta_salto`)
   y en Task 4 (`test_build_falla_si_serie_invalida`).
4. **ETF cotizado en otra moneda** (CSPX.AS y CNDX.AS cotizan en USD, VWCE.DE en EUR). La conversión tiene que usar la
   moneda de cotización declarada en la configuración. Se prueba en Task 2 (`test_a_moneda_convierte_usd_a_eur`).
5. **La página abierta sin `?pais=` o con un valor inválido** tiene que caer en `es` sin romperse. Se verifica en Task 5
   (paso de verificación en el navegador).

### Task 2: Construcción de series

**Files:**
- Create: `ahorro/series.py`, `tests/test_series.py`

**Interfaces:**
- Consumes: nada de otras tasks.
- Produces (en `ahorro/series.py`):
  - `empalmar(real: pd.Series, proxy: pd.Series, ter_diff: float) -> pd.Series`: usa `real` desde su primer mes. Antes de eso usa los retornos mensuales de `proxy` menos `ter_diff/12`, encadenados hacia atrás para que el nivel coincida en el primer mes real.
  - `a_moneda(precios: pd.Series, de: str, a: str, eurusd: pd.Series) -> pd.Series`: `eurusd` = USD por 1 EUR. De USD a EUR divide; de EUR a USD multiplica; si `de == a`, devuelve la serie igual.
  - `cuenta_modelada(tasa_anual_pct: pd.Series, spread=0.5, piso=0.0) -> pd.Series`: índice que arranca en 100 y capitaliza mes a mes `max(tasa - spread, piso)/100/12`.
  - `validar(nombre: str, s: pd.Series, salto_max: float) -> list[str]`: devuelve un mensaje por cada mes con `|retorno mensual| > salto_max`, por cada `NaN` interno y si la serie no cubre 2010-01. Una lista vacía significa que la serie está bien.
  - `recortar(series: dict[str, pd.Series], desde="2010-01") -> dict[str, pd.Series]`: corta todas al rango `[desde, último mes común]`.

### Task 3: Fuentes y caché

**Files:**
- Create: `ahorro/fuentes.py`, `tests/test_fuentes.py`

**Interfaces:**
- Produces (en `ahorro/fuentes.py`). Cada `bajar_*` devuelve un `pd.Series` mensual con `PeriodIndex`:
  - `bajar_yahoo(ticker: str) -> pd.Series`: `yfinance.download(ticker, start="2005-01-01", interval="1mo", auto_adjust=True)`, columna Close, con índice a período mensual.
  - `bajar_hicp(geo: str) -> pd.Series`: API JSON de Eurostat `https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/prc_hicp_minr?geo={geo}&coicop18=TOTAL&unit=I15&format=JSON`.
  - `bajar_fred(serie_id: str) -> pd.Series`: `https://fred.stlouisfed.org/graph/fredgraph.csv?id={serie_id}`. Diaria o mensual; tomar el promedio del mes para tasas y el último valor para índices.
  - `bajar_bce(clave: str) -> pd.Series`: `https://data-api.ecb.europa.eu/service/data/{flujo}/{resto}?format=csvdata`. Las diarias se pasan a promedio mensual. Claves: `EXR/M.USD.EUR.SP00.E`, `EST/B.EU000A2X2A25.WT` y `EON/D.EONIA_TO.RATE`.
  - `actualizar(nombre: str, bajar: Callable[[], pd.Series], dir_raw=Path("data/raw")) -> pd.Series`: lee `data/raw/{nombre}.csv` si existe y llama a `bajar()`. Si funciona, combina (lo nuevo pisa lo viejo en los meses repetidos), guarda y devuelve. Si `bajar()` lanza una excepción, loguea `AVISO: {nombre} sin actualizar: {error}` a stderr y devuelve el caché. Si no hay caché, propaga la excepción.

```python
# tests/test_build.py
import pandas as pd, pytest, yaml
from ahorro import build

def plano(n=200, inicio="2009-01", r=0.003):
    return pd.Series([100 * (1 + r) ** i for i in range(n)], index=pd.period_range(inicio, periods=n, freq="M"))

@pytest.fixture
def config():
    return yaml.safe_load(open("config/instrumentos.yaml"))

def obtener_falso(nombre):
    if "EONIA" in nombre or "EST/" in nombre or "TB3MS" in nombre:
        return pd.Series(2.0, index=pd.period_range("2005-01", periods=260, freq="M"))
    if "EXR" in nombre:
        return pd.Series(1.1, index=pd.period_range("2005-01", periods=260, freq="M"))
    return plano()

def test_build_produce_las_tres_vistas(config):
    out = build.construir(config, obtener_falso)
    assert set(out) == {"es", "ea", "us"}
    g = out["es"]["grupos"]
    assert [x["id"] for x in g] == ["liq", "med", "jub"]
    assert all(sum(i["destacado"] for i in x["instrumentos"]) == 1 for x in g)
    assert out["es"]["desde"] == "2010-01"
    assert len(out["es"]["grafico"]["meses"]) == 121

def test_build_recorta_al_ultimo_mes_comun(config):
    def corto(n):
        s = obtener_falso(n)
        return s.iloc[:-3] if n.startswith("hicp:") else s
    out = build.construir(config, corto)
    assert out["es"]["datos_al"] == str(plano().index[-4])

def test_build_falla_si_serie_invalida(config):
    def roto(n):
        s = obtener_falso(n)
        if n == "yahoo:VWCE.DE": s = s.copy(); s.iloc[-10] = s.iloc[-11] * 0.04
        return s
    with pytest.raises(ValueError, match="VWCE"):
```
